# ✂️ Rock-Paper-Scissors

A fun and interactive **Rock-Paper-Scissors** game built with vanilla HTML, CSS, and JavaScript. Challenge the computer and be the first to reach **5 wins** to claim victory!

---

## 🎮 Live Demo

Open `index.html` directly in your browser — no server or installation required.

---

## ✨ Features

- 🤜 Choose **Rock**, ✂️ **Scissors**, or 📄 **Paper** with a click
- 🤖 Computer makes a random choice every round
- 📊 Live **score tracking** for both you and the computer
- 🏆 Game ends automatically when either side reaches **5 wins**
- 🔄 **Reset** button to restart the game at any time
- 📱 **Responsive design** — works great on desktop and mobile

---

## 🕹️ How to Play

1. Click **Rock**, **Scissors**, or **Paper** to make your move.
2. The computer will instantly make its own random choice.
3. The result of each round is displayed along with the updated score.
4. The first to reach **5 wins** is declared the overall winner.
5. Click **Reset Game** to start over.

## 📜 Game Rules

| Your Choice | Beats      |
|-------------|------------|
| 🪨 Rock     | ✂️ Scissors |
| ✂️ Scissors | 📄 Paper    |
