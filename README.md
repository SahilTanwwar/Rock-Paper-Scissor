# Rock-Paper-Scissors 🎮

A simple, browser-based **Rock-Paper-Scissors** game built with HTML, CSS, and vanilla JavaScript.

## 🕹️ How to Play

1. Open `index.html` in your browser.
2. Click **Rock**, **Paper**, or **Scissors** to make your move.
3. The computer picks a random move.
4. The result is displayed after each round.
5. First to **5 wins** takes the game!
6. Click **Reset Game** to start over at any time.

## ✨ Features

- Instant results after every move
- Live score tracking for both player and computer
- Game ends automatically when someone reaches 5 wins
- Reset button to restart the game
- Responsive design — works on mobile and desktop

No build steps or dependencies needed — it's pure HTML/CSS/JS.

1. Clone the repository:
   ```bash
   git clone https://github.com/SahilTanwwar/Rock-Paper-Scissor.git
   ```
2. Open `index.html` in any modern web browser.
